# UX Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 8 UX improvements: cursor follows nesting indent, urgency capped at 5 with per-level colors, default name + inline edit on create, h/l pane switching, always-vertical-centering, inline input on the cursor row, help exits on any key.

**Architecture:** All changes are inside `internal/app` plus the `theme`/`lua` packages for urgency colors. No schema change, no data migration. Rendering lives in `view.go`/`renderers.go`; input mode is `input.go`; key dispatch is `keymap.go`/`update.go`.

**Tech Stack:** Go, bubbletea, lipgloss, gopher-lua.

func TestCursorAlignsWithIndent(t *testing.T) {

    m.SetFocus(PaneTodo)
    // build a 2-level tree
    root := m.selectedTodo()
    child := &model.Todo{Description: "child", Pending: true, ParentTodoID: &root.ID}

    m.store.SaveTodo(child)
    m.RefreshFromStore()

    // marker "> " must not be the first visible char on the nested row

    }
}
